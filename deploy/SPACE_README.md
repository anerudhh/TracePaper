# TracePaper

Research documents, grounded answers, and source-page citations in a navy-and-white workspace.

Source: https://github.com/anerudhh/TracePaper

This Space uses Supabase for persistent files, passages, and answer history. Each visitor provides their own Gemini or OpenAI key in Response settings; model keys stay in tab memory and are not stored. Workspace access is password protected and documents are shared among people with that password. Free hosting may sleep and has usage quotas.
